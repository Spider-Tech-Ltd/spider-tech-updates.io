# Changelog — Spider Tech Forum

All notable changes to the Spider Tech Forum project will be documented in this file. This project follows a professional technical standard for communication between Developers, PMs, and Stakeholders.

## [1.0.0-redesign] - 2026-03-19

### 🚀 Added
- **New Branding System:** Implemented a unified design system with brand orange (`#f48221`), Poppins headers, and Open Sans body text.
- **Two-Column Layout:** Structural shift in `index.php` from a single-column block to a professional 8/4 split (Feed/Sidebar).
- **Interactive Sidebar:** Added `sidebar.php` featuring ranked Trending Topics, a weekly Contributor Leaderboard, and community CTAs.
- **Advanced Feed Features:** Added support for **Pinned Announcements** (with warm highlighting) and **🔥 Hot** activity badges.
- **Enhanced Metadata:** Thread items now display "Last Reply" details (Author + Timestamp) in the main feed view.

### 🎨 Fixed & Improved
- **Hero Section Overhaul:** Replaced static hero with a dynamic, animated version featuring soft radial gradients and dual action buttons.
- **Category Grid Refinement:** Improved visual separation of community topics with a soft gray background and interactive card hover states.
- **Mobile Responsiveness:** 
  - Optimized Hero stats for vertical stacking on narrow viewports.
  - Implemented responsive grid behavior for category cards (3 → 1 columns).
  - Ensured sidebar widgets correctly stack below the primary feed on mobile devices.

### 🧹 Removed
- Temporary Stitch UI design assets and static HTML placeholders to keep the production includes directory clean.
